**Estimated time**: ⏱️ ~30 minutes

Learn how durable applications survive crashes and outages by breaking one yourself. Hands-on, no code or sign-up required.

In these exercises, you'll interact with a simple food delivery application. You'll place an order and watch it run through to the end. The catch? At any point, you can switch off any part of the application (for real), watch the order pause, restore it, and watch it recover. Go ahead, try and break it. We dare you.

When you're done, head over to <Link to="/getting_started">Get Started with Temporal</Link>.
